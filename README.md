## 修改
### 基于[fantasytyx/bv](https://github.com/fantasytyx/bv)修改，新增功能和变更如下：

- 播放
    - 支持自动跳过番剧/影视片头/片尾，需从设置-播放设置中开启
    - 支持配置视频播放时默认从头开始或从历史记录位置开始，在设置-播放设置中设置
    - 已重构弹幕库，修正部分弹幕问题
    - 新增一键三连功能，使用播放器右侧菜单/界面设置-长按确定键
    - 支持显示同时观看人数
    - 支持显示视频图文评论
    - 新增播放器内核VLC。VLC内核兼容性更强，颜色更饱满，但不支持杜比视界
    - 支持视频弹幕过滤，过滤等级 1-10，1 不过滤，10 最强过滤
    - 新增弹幕智能过滤
    - 支持互动视频，支持互动选项选择
    - 支持视频内广告跳过，需从设置-广告助手开启。（由[小电视空降助手](https://github.com/hanydd/BilibiliSponsorBlock)提供支持）
    - 重构播放界面
        - 播放列表支持封面、观看数、弹幕数、时长显示
        - 底部控制面板重排按钮布局，新增支持显示简介与音频模式
        - 右侧设置面板 UI 重构，移除部分设置
    - 支持副字幕，可以同时展示双语字幕
- 主屏
    - 主页左侧抽屉导航支持自定义显隐和排序
    - 首页导航项自定义排序与隐藏，设置-界面设置中配置
    - 界面网格列数可配置设置，设置-界面设置中配置
    - 右上角本地时间显示
    - PGC 详情增加模糊背景效果
    - PGC 页小卡片增加类型、集数等组件
    - 详情页高亮标注历史记录或EP
    - 详情页自动滚动到历史记录或EP
    - 优化视频卡片时长显示布局
    - 详情页、播放页支持查看视频评论
    - 支持各种动态（图文、专栏、视频）显示
    - UGC 分区支持自定义显隐和排序
    - 主页全部重构，支持统一管理焦点，支持切换动画开关（默认关闭）
    - 新增主页的用户内容页和简洁设置页，移除原用户弹窗
    - 视频、UGC、PGC 详情页均以 Hero 风格完全重构
    - 搜索页、搜索结果页 UI 完全重构
    - 支持充电、开通会员、付费
    - 评论支持翻译
- 其它
    - 优化 Coil 图片加载
- 直播功能(<span style="color: red;">Deprecated 不再更新！</span>)
    - 集成 B站直播功能，需从设置-直播开启
    - 支持设置清晰度与编码
    - 直播分区导航重构，支持主分区与子分区两级切换
    - 直播弹幕实时显示
    - 支持直播弹幕按用户等级过滤（0-60），0 不过滤，60 过滤 60 级以下用户弹幕
    - 直播间新增底部控制面板，支持关注 UP主与单独上报历史
