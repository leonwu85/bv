## 修改
### 基于[fantasytyx/bv](https://github.com/fantasytyx/bv)修改，新增功能和变更如下：

- 播放
    - 支持自动跳过番剧/影视片头/片尾，需从设置-播放设置中开启
    - 支持配置视频播放时默认从头开始或从历史记录位置开始，在设置-播放设置中设置
    - 已重构弹幕库，修正部分弹幕问题
    - 新增一键三连功能，使用播放器右侧菜单/界面设置-长按确定键
    - 支持显示同时观看人数
    - 支持显示视频图文评论
    - 新增播放器内核VLC。VLC内核兼容性更强，颜色更饱满，但不支持杜比视界
    - 新增播放器内核 MPV，Mobile/TV 端均可使用，支持点播、直播和官方 mpv-android 组件下载
    - 支持视频弹幕过滤，过滤等级 1-10，1 不过滤，10 最强过滤
    - 新增弹幕智能过滤，优化分段增量合并与首屏/跳转后的即时加载，降低开启过滤时的弹幕延迟
    - 弹幕合并升级，支持归一化、文本相似和拼音相似合并，并优化纯标点弹幕处理
    - 支持互动视频，支持互动选项选择
    - 支持视频内广告跳过，需从设置-广告助手开启。（由[小电视空降助手](https://github.com/hanydd/BilibiliSponsorBlock)提供支持）
    - 重构播放界面
        - TV 播放列表支持选集、分 P、合集和互动视频分类展示，补充当前/总数、封面、观看数、弹幕数、时长和播放状态，并自动定位当前播放项
        - 底部控制面板重排按钮布局，新增支持显示简介与音频模式
        - 右侧设置面板 UI 重构，移除部分设置
    - 支持副字幕，可以同时展示双语字幕
    - 支持字幕智能显示，默认开启，可按 UP 主记住字幕语言并在下次播放时自动显示
    - 支持播放页评论分屏，可以边播放边查看评论/回复
    - 优化连播目标解析，支持不跨页面连播
    - TV 支持预取下一集播放信息与无缝自动连播，切换分 P/分集时保留当前播放上下文
    - TV 支持离线缓存/离线播放，可从详情页批量缓存分 P/分集或在播放页缓存当前视频；同步保存视频、音频、弹幕和元数据，支持画质降级、任务暂停/继续及批量管理
    - TV 点播切换分辨率时保留当前播放位置，避免重新从头播放
    - TV 点播支持频繁缓冲分级恢复，先提示切换 CDN，仍不流畅时再提示降低清晰度，并从当前进度继续播放；手动跳转进度不会误触发恢复策略
    - 改进点播链接 CDN 选择策略，支持配置 CDN 服务并显示选择结果
    - MPV 支持视频输出模式和参数配置，可调整 vo、gpu-context、gpu-api、hwdec、缓存等参数，并优化音频加载、播放结束事件和播放输出兼容性
    - MPV 支持超分辨率，可选择效率/质量两档 Anime4K 与 FSRCNNX 方案
    - 支持视频帧率策略选项，弹幕刷新与屏幕刷新率解耦
    - 支持弹幕速度模式，可选择跟随视频、阅读优先或自定义弹幕速度
    - 优化弹幕加载会话、预取和蒙版加载，支持蒙版双缓冲/降采样
    - 优化弹幕切片预取与追赶加载，降低跳转后弹幕缺口概率
    - 优化弹幕开关状态管理，减少播放状态切换时的弹幕状态错乱
    - TV 播放底部控制面板支持界面缩放比例，视频旋转入口默认隐藏
    - TV 播放底部控制面板支持自定义标题/信息区/按钮行/进度条大小和按钮顺序
    - TV 播放页支持为弹幕、评论、字幕、一键三连和推荐视频绑定遥控器快捷键
    - TV 播放页支持双击下键唤出推荐视频，字幕快捷开关开启时自动优选中文字幕
    - 点播播放支持 Web/APP 接口双向兜底、DURL 单文件流和按播放链接调整请求头，改善空流及 APP 链接播放失败
    - TV 播放设置支持视频编码优先级与 H.265 优先级配置
    - 播放触发风控时支持完成极验验证后自动重试请求
    - Android 8.0 以下 TV 设备的点播弹幕自动降级为普通 View，并禁用不兼容的弹幕蒙版
    - 优化竖屏视频内容几何、播放器监听生命周期与弹幕蒙版对齐
- 主屏
    - 主页左侧抽屉导航支持自定义显隐和排序
    - 首页导航项自定义排序与隐藏，设置-界面设置中配置
    - 界面网格列数可配置设置，设置-界面设置中配置
    - 右上角本地时间显示
    - PGC 详情增加模糊背景效果
    - PGC 页小卡片增加类型、集数等组件
    - 详情页高亮标注历史记录或EP
    - 详情页自动滚动到历史记录或EP
    - 优化视频卡片时长显示布局
    - 详情页、播放页支持查看视频评论
    - 支持各种动态（图文、专栏、视频）显示
    - 动态页支持全部、投稿、番剧、专栏、UP 筛选和未读动态计数
    - UGC 分区支持自定义显隐和排序
    - 主页全部重构，支持统一管理焦点，支持切换动画开关（默认关闭）
    - 新增主页的用户内容页和简洁设置页，移除原用户弹窗
    - 视频、UGC、PGC 详情页均以 Hero 风格完全重构
    - 搜索页、搜索结果页 UI 完全重构
    - 支持充电、开通会员、付费
    - 评论支持翻译
    - 新增空状态展示，优化历史记录/稍后再看删除体验
    - TV 新动态页支持充电受限内容二维码弹窗，可使用手机扫码访问
    - TV UP 主空间重构，支持动态/投稿分栏、关注状态和新版空间布局
    - TV UP 主空间新增主页，聚合最新投稿与动态，优化焦点导航、顶部操作和刷新体验
    - 优化 TV 推荐、热门和动态列表的分页加载与滚动焦点表现
    - TV 端新增消息中心，支持私信、消息通知、联系人和会话操作
    - TV 首页与内容页支持相邻页面预加载和有限保活，改善切换、焦点与滚动体验
    - TV 主页接入 Baseline Profile 和渐进式封面加载，优化首次切换 Tab、页面预加载、焦点切换及图片解码/纹理上传性能
    - TV 设置支持 4K 界面渲染模式，可在保持视频原分辨率输出时以 1080p 渲染界面
    - 优化 TV UGC 合集与视频详情标签 UI 表现
- 移动端
    - 补全首页、动态、内容中心、我的、收藏、历史、追番、稍后再看、PGC 索引/详情、搜索和设置等页面
    - 移动端播放器补全起播位置、历史心跳、弹幕防遮挡、控制器和进度条交互
    - 移动端动态支持发布文字/图片、话题、@、表情、投票、直播预约、定时发布和私密发布
    - 移动端动态卡片支持稍后再看、保存图片、分享、临时屏蔽 UP 和举报
    - 移动端评论支持展示和参与投票，话题链接可打开支持刷新、分页及折叠展开的话题动态流
    - 移动端支持点播视频弹幕发送，支持滚动/顶部/底部、字号和颜色选项
    - 移动端播放器支持分段进度条，并优化关闭自动播放时的封面手动播放体验
    - 移动端播放器完善 PGC/UGC 选集与切集状态同步，支持 DLNA/UPnP 投屏及播放、暂停、跳转、停止和更换设备等会话控制，并支持带播放/暂停操作的系统画中画
    - 移动端支持随设备倾斜自动进入全屏，可配置横屏触发角度
    - 移动端支持离线缓存/离线播放，可缓存视频、音频和弹幕，支持任务暂停/继续、批量缓存和缓存管理
    - 移动端直播支持发送弹幕、直播表情、点赞直播间，并优化直播间信息展示
    - 移动端默认直播编码从 FLV 调整为 HLS，TV 端保持不变
    - 移动端评论输入支持表情、@、图片评论和同步转发到动态
    - 移动端评论支持点赞、点踩、复制、自由复制、分享、举报、加入黑名单和访问评论用户空间
    - 移动端图片预览支持保存到相册
    - 移动端视频卡片支持复制 BV 号、稍后再看、访问 UP 空间、不感兴趣、拉黑 UP 和无痕模式
    - 移动端用户空间支持主页、动态、投稿、收藏、追番分栏，以及关注、直播间、充电信息、分享和黑名单等操作，并完善外部链接打开兼容性与失败提示
    - 移动端动态、转发动态和视频播放页支持跳转 UP 主空间，视频播放页支持关注 UP，动态卡片支持点赞
    - 移动端我的页面重构，支持账号切换/移除、用户数据概览、快捷入口、离线缓存入口和收藏夹预览
    - 移动端集成私信功能，支持消息中心、私信会话、联系人、互动通知、未读提醒和文本/图片消息发送
    - 移动端收藏夹支持当前收藏夹搜索、排序、新建/编辑/删除、公开状态设置、清理失效内容和移出收藏
    - 移动端观看历史支持按标题、UP 主或 BV 号搜索、暂停记录、单项删除、删除已观看记录和全部清空；稍后再看支持搜索、排序、列表播放及分类清理
    - 移动端搜索新增专栏分类，视频结果支持按排序方式、时长、分区和子分区组合筛选；搜索建议支持输入防抖并避免旧请求覆盖新关键词
    - 支持独立的移动端播放设置来源和偏好配置
    - 移动端新增音视频设置，支持播放器内核、CDN、画质/音质、直播流、解码、MPV 参数与缓冲配置
    - 移动端广告助手支持手动/自动跳过和 API 服务器配置
    - 优化移动端登录、用户切换、首页分区样式、搜索体验和主题适配
    - 移动端外观设置新增主题配色选择，支持中国传统色固定配色
    - 优化移动端主页、动态、播放器和设置界面，并支持隐藏背景图片
    - 移动端外观设置支持 9 档字体大小和导入自定义字体
    - 移动端 PGC 详情页重构，支持继续播放、历史进度、正片/附加分组、分集评论和详情信息展示
    - 移动端新增跟随明暗主题的启动页
- 其它
    - 优化 Coil 图片加载
    - 优化图片尺寸与 TV 图片内存策略，降低动态、评论和用户空间图片加载压力
    - 移动端幻想卷轴背景资源改用 WebP，并收紧 gRPC Proto 生成范围以减小安装包体积
    - 扫码登录支持按接口类型请求二维码，并提供自动刷新与手动刷新
    - 提升动态接口数值字段兼容性，修复 PGC 索引、APP 播放及用户列表加载等异常
    - 更新内容支持显示图片
    - 支持启动时每日自动检查更新，Mobile/TV 端发现新版本时提示更新内容和下载入口；手动检查更新遇到 GitHub API 请求受限时提供 Releases 二维码下载入口
    - 支持手动签名发布构建工作流
    - 构建升级至 AGP 9.2.1 并启用内置 Kotlin，迁移 Android/Compose 废弃 API，补齐播放器 ProGuard 规则
